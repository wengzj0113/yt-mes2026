# 批次详情 OCV 参数编辑抽屉设计

## 1. 背景

批次详情页已经使用右侧 `el-drawer` 打开分选等工序页面，但 OCV1/OCV2 当前没有接入该入口。现有 `Ocv1Page` 和 `Ocv2Page` 的职责是按电芯码录入测试结果，直接复用它们会让批次详情中的工序卡片进入测试录入页面，不能满足“编辑该批次工序参数”的需求。

本次变更只处理批次详情页的 OCV1/OCV2 参数编辑入口。OCV 测试数据上传入口和接口不改变。

## 2. 目标与非目标

### 目标

- 批次详情点击 OCV1 测试、OCV2 测试卡片时，从右侧打开与分选相同的抽屉。
- 抽屉标题明确标识“参数编辑”，避免与测试数据录入混淆。
- OCV1/OCV2 参数表单与分选保持同一字段结构：设备编号、OCV 电压范围、内阻范围、容量范围、操作员。
- 表单使用现有工序草稿查询和保存接口，保存后关闭抽屉并刷新批次工序状态。
- 保留现有 OCV1/OCV2 测试数据录入页面，供现场测试录入流程继续使用。

### 非目标

- 不在批次详情参数抽屉中录入电芯码、OCV 测试值、测试时间或 K 值。
- 不修改 OCV 上传 API、历史记录规则或数据库结构。
- 不改变分选参数页面的业务字段和保存接口。

## 3. 交互设计

1. 用户在批次详情的“工序数据”中点击 OCV1 测试或 OCV2 测试卡片。
2. 页面从右侧打开 `600px` 抽屉，行为与分选一致。
3. 抽屉外层标题为 `OCV1测试 - 参数编辑` 或 `OCV2测试 - 参数编辑`。
4. 抽屉内容显示批次号和参数编辑卡片，卡片标题同样带有 `参数编辑` 标识。
5. 参数字段、单位、范围校验、操作员默认值和保存按钮沿用分选页面的结构。
6. 保存成功后按现有工序页面逻辑关闭抽屉，批次详情重新加载工序状态。
7. 关闭抽屉或点击“返回批次”不会进入 OCV 测试录入页面。

## 4. 组件设计

### 4.1 批次详情页

`BatchDetailPage.vue` 增加 OCV 参数编辑组件映射：

- `ocv1` -> OCV1 参数编辑组件
- `ocv2` -> OCV2 参数编辑组件

分选继续映射到 `SortingPage.vue`。导航函数只增加 OCV 的组件和标题配置，不改变现有路由回退逻辑。

### 4.2 OCV 参数编辑组件

新增一个可复用的 `OcvParameterPage.vue`，通过 `mode` 区分 `ocv1` 和 `ocv2`，再由两个轻量包装组件提供明确的工序入口。组件内部复用 `ProcessFormPage.vue`，将 `basePath` 设置为 `processes/ocv1` 或 `processes/ocv2`。

OCV 参数页面只传入 draft 字段，quality 字段为空，因此页面只显示参数保存区，不显示质检提交区。

### 4.3 字段定义

OCV 参数页面使用与分选相同的前端默认字段定义，后端工序主数据返回的字段定义仍由 `ProcessFormPage` 优先加载。字段包括：

- `equipmentCode`：设备编号
- `ocvVoltageRange`：OCV 电压范围，映射 `ocvVoltageMin`/`ocvVoltageMax`，单位 `V`
- `irRange`：内阻范围，映射 `irMin`/`irMax`，单位 `mΩ`
- `capacityRange`：容量范围，映射 `capacityMin`/`capacityMax`，单位 `mAh`
- `operatorName`：操作员，使用当前登录用户作为默认值并保持只读

为避免分选和 OCV 的默认字段定义继续分叉，抽取一个小型共享字段工厂，分选和 OCV 参数页面共同使用。

## 5. 数据流与错误处理

- 页面挂载时通过现有 `useProcessForm` 查询对应批次的工序记录。
- 查询成功后将记录字段和 `extraData` 合并到表单；查询不到记录时保留空表单并允许创建草稿。
- 保存前沿用已有范围校验，最小值不得大于最大值。
- 保存失败沿用现有错误提示，不关闭抽屉，方便用户修正后重试。
- 抽屉关闭后由批次详情重新加载工序状态；不额外请求 OCV 历史测试数据。

## 6. 测试与验收标准

### 自动化测试

- OCV 参数组件为 OCV1/OCV2 生成正确的 `basePath`、标题和共享字段。
- 批次详情包含 OCV1/OCV2 工序卡片时，点击卡片渲染参数编辑组件，而不是测试录入组件。
- 参数编辑页面仍保留分选使用的范围校验和保存行为。
- 前端构建通过，新增和受影响的 Vitest 测试通过。

### 手工验收

- 打开 `/batches/BAT-649729`，点击 OCV1 测试，确认右侧抽屉打开且标题明确为参数编辑。
- 确认 OCV1 表单没有电芯码、测试时间和 K 值字段。
- 对 OCV2 重复检查，确认使用 `processes/ocv2` 的记录和保存接口。
- 修改参数并保存，确认抽屉关闭后批次工序状态刷新。
- 确认现场扫码/工序中心中的 OCV1/OCV2 仍然进入测试数据录入页面。
