# 仪表盘升级设计文档 (Dashboard Upgrade)

## 1. 概述
将现有简单的仪表盘升级为“运营驾驶舱”风格的生产指挥中心，侧重于追溯数据的完整性监控、实时异常告警以及质量趋势分析。

## 2. 设计目标
- **核心定位**：数据中枢型 (Data Hub)。
- **视觉风格**：亮色系 (Light Theme)，采用 Element Plus 规范。
- **关键指标**：追溯完整率 (Center)、质量合格率趋势 (Bottom)、实时告警 (Left)。

## 3. 详细设计

### 3.1 布局架构 (Grid Layout)
采用三栏式网格布局：
- **Top (Stats)**: 4个核心指标卡片（累计批次、在线批次、当日合格率、待处理异常）。
- **Left (Alerts)**: 实时异常流水，展示漏扫码、参数超差等报警。
- **Center (Hub)**: 巨大的圆环图，展示全厂“追溯完整率”。
- **Right (Progress)**: 最近 5-10 个批次的实时工序流转进度。
- **Bottom (Trend)**: 最近 10 个批次的质量合格率波动曲线。

### 3.2 技术实现
- **前端框架**: Vue 3 (Composition API) + TypeScript.
- **UI 组件库**: Element Plus (el-card, el-row, el-col, el-progress).
- **图表库**: ECharts (用于底部趋势图和中心圆环图)。
- **实时性**: 集成现有的 SSE (Server-Sent Events) 或轮询机制，确保异常告警和进度实时刷新。

### 3.3 数据来源 (API)
- `GET /api/batches/stats`: 获取统计概览。
- `GET /api/batches/recent`: 获取最近批次及其工序进度。
- `GET /api/system/logs`: 过滤获取实时异常告警（类型为 ERROR/WARN）。
- `GET /api/quality/trends`: 新增接口，获取最近批次的合格率数据。

## 4. 交互细节
- 点击“实时告警”条目可直接跳转至对应的批次追溯详情页。
- 点击“最近批次”进度条可弹出该批次的工序参数抽屉。
- 仪表盘支持自动刷新（默认 30s）。

## 5. 验收标准
- [ ] 页面布局适配 1080p 及以上分辨率。
- [ ] 实时告警能在发生异常 5s 内出现在列表中。
- [ ] 中心仪表盘能正确反映数据库中所有电芯的扫码覆盖情况。
- [ ] 整体 UI 符合亮色系简约风格。
