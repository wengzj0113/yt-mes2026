# 化成分容参数录入页面布局设计

## 目标

将化成分容参数录入改为与分选出货一致的批次详情右侧弹出抽屉体验，减少页面跳转，并让十个 Excel 定义的参数按业务阶段清晰分组。

## 交互与布局

- 从批次详情页点击“化成分容”后，在右侧打开抽屉，不改变当前批次详情页面上下文。
- 抽屉标题为“化成分容”，顶部显示批次号和“返回批次/关闭”入口，布局参照分选页面。
- 表单分为三组：
  - 活化参数：活化时间、套膜颜色、设备信息；
  - 化成分容参数：化成模板、化成温度、分容模板、分容温度；
  - 分容结果参数：分容后电压范围、分容后内阻范围、容量分级标准。
- 桌面宽度下采用两列或四列紧凑网格，标签、输入框和单位对齐；窄屏时自动变为单列。
- 底部固定操作区保留“保存”和“提交质检”；提交按钮沿用当前完整参数校验和错误提示。
- 已保存草稿重新打开时回填所有字段；关闭抽屉后刷新批次工序状态。

## 数据与兼容性

- 继续使用 `formation-grading` 工序编码和动态工序接口，不改变数据库结构和参数 Key。
- 参数 Key 保持：`activationDuration`、`filmColor`、`equipmentCode`、`formationTemplate`、`formationTemperature`、`gradingTemplate`、`gradingTemperature`、`postGradingVoltageRange`、`postGradingInternalResistanceRange`、`capacityGradeStandard`。
- 保存和提交仍通过统一动态工序表单逻辑，提交时发送完整草稿参数并由后端合并草稿后校验。

## 组件方案

- 新增化成分容专用页面包装组件，复用现有动态表单能力和抽屉承载方式。
- 批次详情组件映射 `formation-grading` 到该页面；直接 URL 访问继续可用。
- 不修改分选页面的现有布局和交互。

## 验证

- 增加批次详情打开化成分容抽屉的组件测试。
- 增加三组参数渲染、字段回填和完整提交载荷测试。
- 运行相关前端测试和生产构建，确认现有动态工序及分选页面不回归。
