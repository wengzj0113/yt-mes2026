# 大屏看板页面设计优化设计文档

## 1. 方案概述
本方案旨在优化现有的大屏看板（`BigScreenPage.vue`），将其升级为**“数据链路与追溯中心”**。通过引入环形拓扑流转图、实时生产异常告警和质量合格率趋势折线图，提升大屏的信息维度、视觉冲击力和实用价值。

* **设计风格**：深色科技风，以青色（#00e5ff）为主色调，辅以绿色（合格/正常）、黄色（预警）、红色（异常/不合格）。
* **核心布局**：
  * **顶部**：核心指标栏（新增追溯电芯、数据完整率、优质品率、异常待处理数）。
  * **左侧**：工序 WIP 列表 + 实时生产异常告警滚动列表。
  * **中间**：13道工序环形拓扑流转图，中心展示核心综合指标（数据完整率/优质品率，带环形进度条和呼吸灯动效）。
  * **右侧**：实时分选结果滚播 + 质量合格率趋势折线图。

## 2. 页面布局与组件设计

### 2.1 顶部指标栏 (Header Metrics)
* **展示指标**：
  * **新增追溯电芯**：当日新增的追溯电芯总量（SSE 实时更新）。
  * **数据完整率**：全厂追溯数据的完整度百分比（SSE 实时更新）。
  * **优质品率**：分选优质品占比（SSE 实时更新）。
  * **异常待处理**：当前未处理的生产异常总数（API 轮询更新）。
* **视觉效果**：使用 DataV 的 `dv-digital-flop` 数字翻牌器，配合青色发光字体。

### 2.2 左侧面板 (Left Panel)
* **组件 1：工序流转 WIP**
  * **内容**：展示 13 道工序当前的在制品（WIP）数量。
  * **数据源**：SSE 实时推送的 `processes` 数组。
  * **视觉效果**：网格布局，每个工序卡片带青色左边框，数字加粗高亮。
* **组件 2：实时生产异常告警 (新增)**
  * **内容**：滚动展示最近的生产异常日志（过滤出“错误”、“异常”、“失败”等关键字的系统日志）。
  * **数据源**：调用 `systemApi.logs` 接口获取，每 30 秒轮询一次。
  * **视觉效果**：红色/黄色警示边框，支持无缝滚动，点击可查看详情（可选）。

### 2.3 中间核心区 (Center Panel)
* **组件：13道工序环形拓扑流转图 (重构)**
  * **内容**：13道工序呈环形均匀分布，中心为“数据神经元”核心。
  * **工序顺序**：配料 -> 涂布 -> 辊压 -> 分切 -> 制片 -> 卷绕 -> 装配 -> 烘烤 -> 注液 -> 包膜 -> 化成 -> 分容 -> 分选。
  * **中心区域**：展示“数据完整率”或“优质品率”的环形进度条，带顺时针旋转的渐变边框和呼吸灯投影。
  * **视觉动效**：
    * 使用 SVG 绘制节点和连接路径。
    * 节点颜色根据 WIP 状态动态变化（正常为青色，积压过多为黄色，设备异常为红色）。
    * 光点动画（`<animateMotion>`）沿着环形路径流动，表示数据的实时流转。

### 2.4 右侧面板 (Right Panel)
* **组件 1：实时分选结果滚播**
  * **内容**：滚动展示最新的分选结果（条码、电压、内阻、档位）。
  * **数据源**：SSE 实时推送的 `sorterLogs` 数组。
  * **视觉效果**：使用 DataV 的 `dv-scroll-board` 滚动看板，青色表头，深色交替行背景。
* **组件 2：质量合格率趋势折线图 (新增)**
  * **内容**：展示最近 10 个批次的质量合格率趋势。
  * **数据源**：调用 `qualityApi.getTrends` 接口获取，每 30 秒轮询一次。
  * **视觉效果**：使用 ECharts 绘制科技感折线图，带青色渐变面积阴影，无网格线，适配大屏尺寸。

## 3. 数据集成与接口设计

### 3.1 SSE 实时数据流 (`/api/dashboard/stream`)
保持现有的 SSE 连接，数据结构如下：
```json
{
  "topMetrics": {
    "totalCells": 1245,
    "coverageRate": 98.5,
    "goodRate": 92.1
  },
  "processes": [
    { "name": "配料", "wip": 12 },
    { "name": "涂布", "wip": 8 }
    // ... 共 13 道工序
  ],
  "sorterLogs": [
    ["CELL001", "3.21", "15", "A档"],
    ["CELL002", "3.20", "16", "A档"]
  ]
}
```

### 3.2 API 轮询接口
1. **异常日志接口**：
   * **方法**：`systemApi.logs({ pageSize: 10 })`
   * **过滤逻辑**：前端过滤出 `action` 包含“错误”、“异常”、“失败”的日志，展示在异常告警列表中。
2. **质量趋势接口**：
   * **方法**：`qualityApi.getTrends()`
   * **数据结构**：返回最近 10 批次的批次号和合格率，用于绘制折线图。
3. **异常待处理数**：
   * **方法**：`batchApi.getStats()`
   * **数据结构**：获取 `abnormalCount` 展示在顶部指标栏。

## 4. 实施步骤规划
1. **组件准备**：
   * 引入 ECharts 相关组件（折线图）。
   * 准备 SVG 环形拓扑图的静态结构和样式。
2. **逻辑开发**：
   * 在 `BigScreenPage.vue` 中引入 `systemApi`、`qualityApi` 和 `batchApi`。
   * 实现异常日志和质量趋势的数据加载与定时轮询（30秒）。
   * 实现 SVG 节点的动态绑定（根据 `processes` 数据更新节点 WIP 数值和状态颜色）。
3. **界面重构**：
   * 重构 `BigScreenPage.vue` 的模板结构，划分为左、中、右三栏。
   * 替换中间的占位符为 SVG 环形拓扑图。
   * 在左侧下方加入异常告警滚动列表。
   * 在右侧下方加入质量趋势折线图。
4. **调试与优化**：
   * 调试 SSE 实时数据与 API 轮询数据的协同更新。
   * 优化 SVG 动效的性能，确保在大屏上流畅运行。
   * 适配 `ScaleScreen` 的缩放比例，确保在不同分辨率下不失真。
