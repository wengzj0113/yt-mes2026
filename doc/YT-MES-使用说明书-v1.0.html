第一章

系统简介

YT-MES 是一套面向锂电池电芯生产的全流程追溯系统，覆盖从原材料配料到成品分选的 13 道核心工序。

1.1 系统概述

YT-MES（Yuntong Manufacturing Execution System）以批次为主线，串联电芯生产的 配料→涂布→辊压→分切→制片→卷绕→装配→烘烤→注液→顶封→化成→分容→分选共 13 道工序。 系统提供批次管理、工序维护、现场扫码录入、质量检验、原材料仓储、大屏看板以及电芯级全生命周期追溯功能。

1.2 核心功能

功能模块说明
批次管理创建、查询、跟踪生产批次的全生命周期状态
工序管理维护13道工序字典（名称、编码、排序、启停），管理员专属
现场扫码录入扫码枪扫批次条码，聚合操作台中沉浸式录入各工序数据
质量检验记录各工序质检结果，追踪不合格品处置
原材料仓库管理正极/负极/电解液等物料的入库、领用与批次关联
电芯追溯扫描电芯条码，秒级获取从原料到成品的完整生产履历
大屏看板工业级数据大屏，SSE实时推送，展示13道工序数据链路
用户与权限4种预设角色，页面级RBAC权限控制
分选机接口硬件设备REST API，支持单条实时上传与批量表格导入

序号工序名称编码说明

2涂布coating浆料均匀涂覆在集流体表面
3辊压roller-pressing极片辊压压实

打开浏览器（推荐 Chrome / Edge），在地址栏输入系统地址后，将看到以下登录界面：

图 2-1：YT-MES 系统登录界面

第四章

批次管理

批次是生产管理的核心单元，批次号串联所有工序记录和电芯条码。

图 4-1：批次管理列表页面

4.1 批次列表

从左侧导航栏"批次管理"进入，您可以：

  • 搜索 — 按批次号、产品型号、产品规格等关键字搜索
  • 筛选 — 按批次状态筛选
  • 分页 — 支持分页浏览，可切换每页条数

4.2 创建批次

在批次列表页面点击"新建批次"按钮
在弹出的对话框中填写产品型号、规格、车间、班次、计划数量等信息
点击"确定"提交，系统自动生成唯一批次号
批次号规则：{工厂代码}{年份后两位}{月份字母}{4位随机字符}，例如 WT26A1XZ8。

4.3 批次详情

点击批次号进入详情页，可查看：批次基本信息、13道工序完成状态总览、已导入电芯列表、各工序快速入口。

4.4 批次状态说明

状态编码说明
草稿1批次已创建，尚未开始生产
进行中2已有工序开始记录
已完成3所有工序已完成
已关闭4批次关闭，不可再修改
第五章

工序管理

工序字典的集中维护中心，支持工序的增删改查、排序调整和启用/停用控制。

图 5-1：工序管理主数据页面

5.1 功能概述

"工序管理"是系统的工序主数据字典。在这里您可以维护13道标准工序的名称、编码、排序号 以及启用/停用状态。工序字典中的变更是驱动"现场扫码录入"操作台的唯一数据源。

5.2 权限说明

重要：工序管理采用页面级 RBAC 权限控制——
  • 所有登录用户均可查看工序列表和搜索筛选
  • 仅管理员（admin）可见右上角"新增工序"按钮和列表中"编辑/删除"操作列
如果您以非管理员账号（如 operator1）登录，将看不到新增和编辑按钮。

5.3 搜索与筛选

顶部搜索栏支持：按关键字（工序编码/名称模糊搜索）和状态（启用/停用）筛选。

5.4 新增/编辑工序

管理员点击"新增工序"按钮，在弹窗中填写工序编码、名称、排序号和状态后保存。编辑时编码不可修改。

5.5 删除与安全防错

安全机制：如果某工序的数据表中已有生产记录，系统将拦截删除操作，提示"该工序已被历史生产批次使用过，无法删除，建议将其停用"。建议使用停用而非删除来管理过期工序。

5.6 与现场扫码录入的联动

工序字典中的数据会实时影响"现场扫码录入"操作台——停用一个工序后，车间操作台对应的卡片将立即消失。

第六章

现场扫码录入

为车间操作人员量身打造的扫码聚合操作台，扫码即工作，零页面跳转。

图 6-1：现场扫码录入操作台

6.1 设计理念

操作工用扫码枪扫描批次条码 → 系统自动展开该批次的全部工序进度卡片 → 点击卡片弹出抽屉弹窗录入数据 → 关闭抽屉继续下一道工序。全程不离开当前页面。

6.2 操作流程

扫码定位 — 在顶部搜索框用扫码枪扫描批次条码（或手动输入批次号），按回车
查看进度 — 系统展示该批次所有工序卡片，颜色标识状态： 未录入 草稿 已提交 已作废
工序录入 — 点击目标工序卡片，右侧弹出抽屉弹窗，填写该工序的参数表单
保存/提交 — 点击"保存草稿"或"提交"按钮
继续下一工序 — 关闭抽屉，操作台保持不刷新，继续点击下一张卡片

6.3 扫码容错

如果扫描的批次号不存在，系统直接报错并清空输入框，不保留无效输入。

6.4 联动机制

操作台加载时从"工序管理"字典中读取所有启用状态的工序并按排序号排列。管理员在工序管理中停用/启用/新增工序时，操作台同步更新。

第七章

电芯追溯

通过电芯条码，秒级获取从原料到成品的完整生产履历。

图 7-1：电芯追溯查询页面

7.1 功能概述

电芯追溯是 YT-MES 的核心功能。每个电芯拥有唯一的32位条码，系统记录该电芯从配料到分选全部13道工序的生产数据。

7.2 追溯查询方式

方式操作结果
按条码搜索输入或扫描32位电芯条码展示该电芯的全部工序数据、KPI参数
按批次搜索输入批次号展示该批次所有电芯及13道工序记录

7.3 数据展示

追溯结果包含：

  • 批次信息卡 — 所属批次基本信息
  • KPI指标卡 — 电压、内阻、容量、K值、等级等
  • 工序状态导航 — 13道工序完成状态的进度条，已完成项高亮
  • 工序详情面板 — 点击某工序后展示设备参数、材料参数、工艺参数、操作信息
应用场景：电芯出现质量问题时，扫码追溯可快速定位问题工序和操作人员。全流程数据满足下游客户对生产透明度的要求。
第八章

大屏看板

工业级数据大屏，定位为"追溯数据神经中枢"，通过SSE长连接实时推送生产数据。

图 8-1：工业级大屏看板

8.1 设计理念

大屏看板采用暗黑背景+蓝色发光线条的科技风格，C位展示13道工序的数据链路流转图， 两侧呈现追溯覆盖率和实时分选结果。数据通过 SSE 推送，图表局部更新无闪烁。

8.2 面板布局

区域位置内容
KPI 指标卡顶部数字翻牌器展示总批次、进行中、已完成、电芯总数
工序数据链路图C位中央13道工序节点+连线，实时高亮已完成工序
追溯覆盖率左侧面板批次追溯覆盖率、电芯数据完整率
实时分选结果右侧面板最新分选电芯数据滚动展示（条码、档位、K值等）

8.3 使用建议

  • 推荐在车间55寸以上4K电视全屏展示（按 F11）
  • 大屏为只读展示，数据自动更新，无需交互
  • 采用等比缩放，1080P和4K分辨率下均完美适配

9.3 权限控制

系统在工序管理页面实现了页面级 RBAC 控制：所有用户可查看工序列表，仅管理员（roleCode=4）可见新增/编辑/删除按钮。菜单侧边栏对所有角色一致可见。

9.4 账号安全

  • 连续 5 次登录失败后账号锁定 15 分钟
  • JWT Token 认证，Access Token + Refresh Token 双Token机制
  • 锁定期间无法登录，15分钟后自动解锁
