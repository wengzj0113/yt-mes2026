云通追溯系统（MES）使用手册

版本 v1.0 — 适用对象：现场操作员、质检员、仓库管理员、系统管理员

1. 系统简介

1.1 系统定位

云通追溯系统（YT-MES）是一套面向锂电池电芯生产企业的制造执行系统（MES），覆盖从原材料配料到电芯分选出厂的13 道关键工序，实现"一物一码、全程可追"。

系统以批次（Batch）为生产主线，以电芯条码（Cell Barcode）为追溯最小单元，自动汇集每道工序的工艺参数、设备信息、操作员、质检结果与分选机测量数据，最终在 Dashboard 与大屏上呈现生产全景。

1.2 核心价值

  • 正向追溯：从原材料 → 工序 → 半成品 → 成品，跟踪每个环节的工艺参数与责任人。
  • 反向追溯：通过电芯条码反查该电芯经历的全部工序、检验结果、分选档位、所在 Pack。
  • 质量管控：在关键工序设置质检节点，不合格品自动置 质量异常，阻断后续流转。
  • 数据集成：对接 OCV 测试机、分选机等硬件，测量数据自动入库。
  • 可视化管理：实时 Dashboard 与车间大屏，呈现生产进度、合格率、设备状态。

2. 快速上手

2.1 浏览器要求

  • 推荐使用 Chrome 100+ / Edge 100+ / Firefox 100+
  • 建议屏幕分辨率 1366×768 或以上
  • 大屏看板模式建议 1920×1080 全屏展示

2.2 系统访问地址

环境主应用地址大屏地址
开发环境http://localhost:5173http://localhost:5173/big-screen
生产环境http://服务器IP:8080http://服务器IP:8081/big-screen

2.3 三步进入系统

打开浏览器，输入主应用地址。
在登录页输入用户名、密码，点击【登录】。
登录成功后自动跳转至工作台，可开始日常作业。
默认管理员账号：用户名 admin，初始密码 admin123。首次登录后请立即修改密码（点击右上角用户名 → 修改密码）。

3. 登录与账号

3.1 登录页

访问系统根地址后自动跳转到登录页 /login。登录界面包含：

  • 用户名：必填，区分大小写
  • 密码：必填，至少 6 位字符
  • 记住我（可选）：勾选后保持登录状态 7 天
  • 注册按钮：新员工自助注册账号（待管理员审核）

3.2 修改密码

点击页面右上角用户名（如"张三"）
在弹出菜单中选择【修改密码】
输入原密码、新密码（≥ 8 位，包含字母与数字）、确认新密码
点击【确认】完成修改
密码安全要求：长度 ≥ 8 位；必须同时包含字母和数字；与最近 3 次密码不能重复。修改后会自动跳转到登录页要求重新登录。

3.3 退出登录

点击页面右上角用户名 → 【退出登录】，确认后清除会话并跳转至登录页。

3.4 忘记密码

联系系统管理员，在【系统管理 → 用户管理】中点击对应用户行的【重置密码】按钮，系统会将密码重置为初始密码 123456，首次登录后请立即修改。

4. 工作台

4.1 进入方式

登录成功后默认进入【仪表盘】模块，路径 /dashboard。也可通过左侧菜单【仪表盘】返回。

4.2 工作台内容

工作台以数据卡片 + 图表形式呈现当日生产全貌：

4.2.1 顶部数据卡片

指标含义更新频率
今日新建批次当天创建的批次总数实时
在制批次状态为"生产中"的批次数实时
今日成品电芯数通过分选入库的电芯总数每分钟
合格率质检通过记录 / 全部质检记录实时

4.2.2 图表区

  • 近 7 日产量趋势：折线图，展示每日入库电芯数
  • 各工序状态分布：柱状图，统计各工序【草稿/待质检/已通过/已驳回】的记录数
  • 异常批次预警：列表卡片，显示状态为"质量异常"的批次

4.3 快捷入口

工作台右侧提供常用模块的快捷卡片：

  • 【新建批次】→ 跳转到批次管理
  • 【扫码录入】→ 跳转到现场扫码录入
  • 【待我质检】→ 跳转到质检管理（仅质检员可见）
  • 【查看大屏】→ 新窗口打开大屏看板

5. 电芯追溯

5.1 模块用途

电芯追溯模块是本系统的核心查询入口，用于通过电芯条码反查该电芯从原料到分选的全部生产履历。

5.2 进入方式

左侧菜单 → 【电芯追溯】，路径 /trace。

5.3 查询电芯

在页面顶部搜索框中输入电芯条码（支持条码枪扫描）
按 Enter 或点击【查询】按钮
系统加载该电芯的全部生产履历（通常 1~2 秒）

5.4 追溯结果展示

5.4.1 电芯基础信息

字段说明
电芯条码唯一标识，与分选机系统对接生成
所属批次批次号，可点击跳转批次详情
容量 (mAh)分选机实测容量
内阻 (mΩ)分选机实测内阻
电压 (V)OCV 测量电压
分选档位A / B / C / D
所在 Pack所属 Pack 编号（未组 Pack 时为空）
上传时间分选机上传到 MES 的时间

5.4.2 全流程工序链

页面中部以时间线 + 工序卡片的形式展示该电芯所经历的全部工序：

  • 工序名称 + 工序记录 ID
  • 操作员、作业时间
  • 工艺参数（温度、压力、速度等）
  • 质检结果（通过 / 驳回 / 异常）
  • 设备编号

5.4.3 K 值与 OCV 数据

对经过 OCV 测试（OCV1、OCV2）的电芯，展示：

  • OCV1 / OCV2 电压、内阻
  • K 值（OCV1 与 OCV2 电压差 / 时间差）
  • K 值单位：mV/天

5.5 异常电芯定位

当客户反馈某只电芯异常时，可通过电芯条码查询该批次全部电芯：

在电芯追溯页输入任一电芯条码 → 点击【查看该批次全部电芯】
系统跳转至批次详情页，展示本批次所有电芯列表
可按档位、内阻、容量排序，定位异常个体
操作建议：追溯查询建议在工位电脑配置条码扫描枪，扫码即可自动填充条码号，避免手工输入错误。

6. 批次管理

6.1 模块用途

批次管理是 MES 的生产主线，每个生产批次对应一个唯一的批次号（BatchNo）。批次下关联：

  • 13 道工序的工序记录
  • 质检记录
  • 电芯条码集合
  • 物料投入信息
  • 设备使用信息

6.2 进入方式

左侧菜单 → 【批次管理】，路径 /batches。

6.3 批次列表

批次列表默认按创建时间倒序展示，支持以下筛选：

  • 批次号：精确 / 模糊搜索
  • 状态：草稿 / 生产中 / 已完成 / 已关闭 / 质量异常
  • 产品型号：下拉选择
  • 创建日期：日期范围
  • 操作员：下拉选择

6.4 新建批次

仅管理员与操作员可创建批次。点击页面右上角【新建批次】按钮，填写：

字段是否必填说明
批次号自动生成格式示例：BN20260811001，可手动调整
产品型号必填下拉选择已配置的产品型号
计划数量必填本批次计划生产电芯数（≥ 1）
投产日期必填默认当天
备注选填特殊说明（如试制批次）

点击【确定】后批次进入 生产中 状态。

6.5 批次状态说明

状态标签含义
草稿草稿已创建但未投产（系统预留态，正常流程不使用）
生产中生产中可执行工序记录的活跃态
已完成已完成所有 13 道工序均完成且质检通过
已关闭已关闭管理员手动关闭，不可再修改
质量异常质量异常任一质检环节不通过，需返工或让步

6.6 批次详情页

点击列表中任一批次号，进入【批次详情】，路径 /batches/{batchNo}。详情页分四部分：

6.6.1 基本信息

展示批次号、型号、计划数量、投产日期、当前状态、操作员、创建/更新时间等。

6.6.2 工序进度看板

以13 工序进度条展示各工序状态：

状态颜色含义
未开始未开始尚未提交任何工艺记录
草稿草稿已填写未提交质检
待质检待质检已提交，等待质检员确认
已通过已通过质检通过，可进入下道工序
已驳回已驳回质检不通过，需返工

6.6.3 工序记录时间线

按时间顺序展示本批次全部工序记录，每条记录可点击展开查看：

  • 工艺参数
  • 投入物料批次
  • 使用设备
  • 操作员 / 质检员
  • 质检结果与备注

6.6.4 电芯明细

批次详情页底部展示本批次全部电芯条码列表，支持：

  • 分选档位分布饼图
  • 电芯明细表（条码、容量、内阻、电压、档位、上传时间）
  • 导出 Excel

6.7 批量操作

操作权限说明
编辑管理员 / 操作员仅可修改备注、计划数量
关闭批次管理员将"生产中"批次强制关闭，不可逆
删除管理员仅允许删除未投产且无子记录的批次
导出全员导出批次详情为 Excel
注意：已关联电芯条码或工序记录的批次不可删除，避免追溯链断裂。

7. 现场扫码录入

7.1 模块用途

现场扫码录入是操作员的日常作业主入口，通过扫码或选择批次快速进入对应工序的录入页面，完成工艺参数填报与提交质检。

7.2 进入方式

左侧菜单 → 【现场扫码录入】，路径 /process-hub。

7.3 页面布局

页面顶部为批次选择区，中部为13 道工序入口网格。

7.4 进入工序录入

点击【选择批次】按钮，弹出批次下拉框（或直接扫描批次号条码）
选择对应批次后，下方13 道工序卡片亮起
点击目标工序卡片（如"配料"），跳转到工序录入页 /processes/{batchNo}/batching
填写工艺参数 →【保存草稿】或【提交质检】

7.5 通用工序录入流程

各工序页面布局一致：

  1. 顶部：批次号、当前工序、状态标签
  2. 中部：工序表单（按工艺字典动态渲染字段）
  3. 底部：【保存草稿】【提交质检】【取消】三个按钮

7.6 各工序字段说明（重点）

7.6.1 配料

字段类型说明
正极材料批次下拉关联物料仓库
负极材料批次下拉关联物料仓库
导电剂下拉关联物料仓库
粘结剂下拉关联物料仓库
配料温度 (℃)数值标准值 ± 5
搅拌时长 (min)数值标准值 ± 10
备注文本选填

7.6.2 涂布 / 辊压 / 分切

主要字段：涂布速度、干燥温度、面密度、压辊压力、分切宽度等。详见【工序主数据】模块中各工序的字段配置。

7.6.3 制片

字段：极片长度、宽度、留白尺寸、极耳位置、检验员、备注等。

7.6.4 卷绕 / 装配 / 烘烤 / 注液 / 顶封

字段以工艺字典为准，必填项带 *。

7.6.5 化成

字段：化成电流、化成电压、化成时长、温度、容量初值等。此工序需质检通过后才能流转到分容。

7.6.6 分容

字段：分容电流、分容电压、测试时长、容量终值、K 值等。

7.6.7 分选

字段说明
OCV 电压范围本次分选允许的电压区间
内阻范围允许的内阻区间
容量范围允许的容量区间
档位划分如 A ≥ 3000mAh，B ≥ 2900mAh 等

7.7 提交质检

9 道带质检的工序完成后，点击【提交质检】：

  • 工序记录状态变为 待质检
  • 该批次自动出现在【质检管理】待办列表
  • 质检员登录后可到【质检管理】完成判定

7.8 作废记录

如发现已提交记录有误，可点击【作废】（仅管理员或本操作员）：

  • 记录状态变为 已作废
  • 批次对应工序状态回到 草稿
  • 可重新填写并提交
最佳实践：每完成一道工序，立即在 MES 录入并提交质检，避免集中补录造成数据失真。

8. Pack 组装录入

8.1 模块用途

用于将分选后的合格电芯组装成电池包（Pack），建立 Pack 与电芯条码的关联关系，便于后续电池组级追溯。

8.2 进入方式

左侧菜单 → 【Pack 录入】，路径 /pack-entry。

8.3 新建 Pack

点击【新建 Pack】按钮
填写：Pack 编号（自动生成，可手改）、所属批次（下拉）
在电芯条码输入框中粘贴或扫描电芯条码（每行一个或逗号分隔）
系统自动校验：条码是否存在、是否同批次、是否已组 Pack
点击【保存】完成组 Pack

8.4 校验规则

校验项失败提示
电芯必须存在电芯条码 XXX 在系统中不存在
电芯必须同批次电芯 XXX 与当前批次不一致
电芯未被组 Pack电芯 XXX 已存在于 Pack YYY
数量限制单个 Pack 电芯数：1 ~ 200

8.5 查看 Pack 详情

在 Pack 列表中点击任一 Pack 编号，可查看：

  • Pack 基本信息（编号、批次、创建时间、创建人）
  • 包含的全部电芯条码
  • 每只电芯的容量、内阻、电压、档位
  • 导出 Excel

8.6 修改 Pack

仅创建人或管理员可修改 Pack。点击【编辑】可增删电芯（前提：被增电芯未组 Pack；被删电芯不会从电芯库删除，只解除关联）。

注意：已出货的 Pack 不可修改。

9. 质量检验

9.1 模块用途

质检模块是 MES 的质量管控核心，所有带质检节点工序的提交记录都需要在此完成通过 / 驳回判定。

9.2 进入方式

左侧菜单 → 【质检管理】，路径 /quality。

9.3 质检待办列表

页面默认显示 待质检 记录，可按以下条件筛选：

  • 工序类型（配料、制片、卷绕、装配、烘烤、注液、顶封、化成、分容）
  • 提交时间范围
  • 批次号
  • 操作员

9.4 质检判定流程

在待办列表中点击任一记录 → 进入质检详情页
查看工艺参数、提交时间、操作员、设备信息
选择检验结果：通过 / 驳回
填写质检备注（驳回时必填，写明不合格原因）
点击【提交】完成判定

9.5 质检结果影响

判定工序状态变化批次状态变化
通过待质检 → 已通过若全部工序通过 → 可标记完成
驳回待质检 → 已驳回批次状态变为"质量异常"

9.6 异常处理

质检驳回后，操作员需在【现场扫码录入】中找到对应工序，重新填写并提交。批次状态从"质量异常"恢复后需质检员在批次详情页点击【恢复生产】。

9.7 质检历史

切换 Tab 至【质检历史】，可查看本账号过往的全部质检判定记录，支持按时间、结果、批次号筛选，可导出 Excel。

质检时效：建议工序提交后 2 小时内 完成质检，避免生产等待。

10. 原材料仓库

10.1 模块用途

原材料仓库用于登记来料入库信息，并为工序录入提供物料批次下拉数据源。

10.2 进入方式

从批次详情页或工序录入页【物料字段】旁的【选择物料】按钮进入，亦可在左侧菜单中查找（如未显示请联系管理员分配权限）。

10.3 物料登记

点击【新增物料】按钮
填写：物料编码、物料名称、规格、单位、来料批次号、来料数量、入库日期、供应商

12. 工序主数据

12.1 模块用途

工序主数据用于配置 13 道工序的字段定义，决定工序录入页面的表单结构。仅管理员可访问。

12.2 进入方式

12.3 工序字典列表

展示 13 道工序的当前配置。每行包含：

  • 工序编号（1~13）
  • 工序中文名
  • 工序英文标识
  • 是否启用
  • 是否有质检
  • 字段数量
  • 操作：编辑、停用

点击【编辑】进入工序字段配置页，可配置：

  • 字段名称（中文）

D. 常见问题 FAQ

Q1: 忘记密码怎么办？

联系系统管理员，由管理员在【系统管理 → 用户管理】中点击【重置密码】，重置后密码为 123456，首次登录强制修改。

Q2: 登录后页面 401 报错或自动跳转回登录页？

可能原因：(1) Token 过期，重新登录即可；(2) 账号被管理员停用，请联系管理员。

Q3: 新建批次后，找不到对应的工序入口？

在【现场扫码录入】页面，先选择批次，再点击下方亮起的工序卡片。请确认批次状态为"生产中"。

Q4: 提交质检后多久能查到质检结果？

实时生效。质检员完成判定后，该批次对应工序状态立即变更。可在【批次详情】或【质检管理 → 质检历史】中查询。

Q5: 分选机上传的电芯数据没有出现在批次里？

检查：(1) 电芯条码是否完整；(2) 该批次是否处于"生产中"或"已完成"状态；(3) 进入【系统管理 → 接口日志】查看上传日志，确认接口调用是否成功。

Q6: 工序录入字段填写错误，能否修改？

草稿状态下可直接修改。已提交（待质检）的记录需先作废（管理员或本人），再重新填写。已质检通过的记录不可修改，如需调整请走返工流程。

Q7: Pack 录入时提示"电芯不存在"？

说明该电芯条码尚未通过分选机上传到 MES，需先完成分选工序并由分选机上传数据。

Q8: 大屏看板不显示数据？

检查：(1) 网络是否可达 MES 服务器；(2) 是否登录了系统（大屏页通常无需登录，但首次访问可能要求鉴权）；(3) 系统时间是否正确（SSE 连接受时间影响）。

Q9: 角色权限不够，如何申请？

联系系统管理员，由管理员在【用户管理】中修改用户的角色。

Q10: 工序字段如何新增？

管理员进入【系统管理 → 工序主数据】，选择对应工序，点击【编辑字段】，新增字段并保存。新字段立即在工序录入页生效。

Q11: 数据保留多久？会丢失吗？

批次、工序、质检、电芯数据永久保留。日志类数据保留 180~365 天（可在系统配置中调整）。建议重要数据定期使用【导出】功能备份。

Q12: 移动端能否使用？

本系统主要面向 PC 浏览器（≥1366×768）。移动端适配不完整，部分表格与图表可能显示异常，建议使用 PC 操作。

Q13: 系统支持哪些硬件对接？

当前支持：分选机（通过标准 HTTP 接口上传电芯数据）。后续可扩展 OCV 测试机、注液机等设备。

E.2 标准作业流程（SOP 速查）

SOP-01：新建批次并投产

【批次管理】→【新建批次】→ 填写批次号、型号、数量 → 保存
【现场扫码录入】→ 选择批次 → 进入"配料"工序
填写配料参数 →【提交质检】

SOP-02：完成一道工序并提交质检

【现场扫码录入】→ 选择批次 → 点击工序卡片
填写工艺参数 →【保存草稿】（可选，用于暂存）
确认无误 →【提交质检】→ 状态变为"待质检"

SOP-03：质检员完成判定

【质检管理】→ 选择"待质检"记录 → 点击进入详情
查看工艺参数 → 选择"通过"或"驳回"
填写备注 →【提交】

SOP-04：电芯反查追溯

【电芯追溯】→ 扫描或输入电芯条码 →【查询】
查看该电芯的全部工序、参数、质检结果
如需追溯同批次 → 点击"查看该批次全部电芯"

SOP-05：新建 Pack

【Pack 录入】→【新建 Pack】→ 填写 Pack 编号、选择批次
扫描或粘贴电芯条码 → 系统校验
校验通过 →【保存】

SOP-06：新增用户

【系统管理 → 用户管理】→【新增用户】
填写用户名、姓名、初始密码、角色、部门
【保存】→ 通知用户登录并修改初始密码
