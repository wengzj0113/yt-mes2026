1. 概述

YT-MES 系统为分选机、OCV1 测试机、OCV2 测试机等外部硬件设备提供标准 REST API 接口，用于将电芯测试数据上传至 MES 系统。

项目说明
接口风格RESTful API
数据格式JSON
认证方式免认证（无需 Token）
Base URLhttp://{服务器IP}:3001/api/cells 或通过 Nginx 转发的 http://{服务器IP}/api/cells
目标数据表cell_barcode（电芯主表）、ocv1_record / ocv2_record（工序记录表）
数据来源标记导入数据时 import_source 自动标记为 'sorter' / 'ocv1' / 'ocv2'
⚠️ 安全提醒：接口免 Token 认证，生产环境必须通过防火墙、网关白名单等方式限制访问来源 IP，仅允许测试设备所在网段调用。

2. 接口列表

设备类型请求方法接口路径用途
分选机POST/api/cells/sorter-upload单条实时上传（每测完一个电芯实时上传）
POST/api/cells/sorter-upload/bulk批量上传（一次性推送本地缓存数据）
OCV1 测试机POST/api/cells/ocv1-uploadOCV1 单条实时上传
POST/api/cells/ocv1-upload/bulkOCV1 批量上传
OCV2 测试机POST/api/cells/ocv2-uploadOCV2 单条实时上传
POST/api/cells/ocv2-upload/bulkOCV2 批量上传

3. 通用规范

3.1 通用响应结构

所有接口统一返回以下 JSON 结构：

{
  "success": true,
  "data": ...,
  "message": "ok"
}

3.2 通用字段兼容性

字段名支持类型说明
capacity string | number 支持数值（如 2660）或范围字符串（如 "2600-2650"）。系统自动将数值转换为字符串。
internalResistance 或 resistance number 支持两个字段名（互为别名），优先读取 internalResistance。
voltage number 支持大数值（如 10000），数据库精度为 DECIMAL(12,4)。

3.3 写入逻辑（覆盖更新）

  • 覆盖更新：若上传的 barcode 在数据库中已存在，系统会自动用新数据覆盖已有字段，不会报错。
  • 允许提前上传：OCV1/OCV2 接口允许在分选机之前上传，系统会自动创建"半成品"电芯记录（仅有 OCV 字段，其他字段为 null）。
  • 批量原子性：批量上传时使用 TypeORM 事务，任一记录校验失败则整批回滚，不会部分写入。

3.4 批次前置条件

所有接口要求 batchNo 已存在于 MES 系统中（先在批次管理页面创建批次），否则返回 404 错误。

4. 分选机 (Sorter) 接口

4.1 单条上传

POST /api/cells/sorter-upload

请求体参数

参数名类型必填说明
barcodestring是电芯条码（最大 32 字符）
batchNostring是所属批次号（最大 16 字符）
capacitystring | number否电芯容量（mAh）
voltagenumber否开路电压（V）
internalResistance / resistancenumber否交流内阻（mΩ）
kValuenumber否K 值（自放电率，mV/h）
gradestring否分选档位（A / B / C / 22）
sortingTimestring否分选时间（ISO 8601 格式）

请求体示例

{
  "barcode": "9146I2101883",
  "batchNo": "BAT-649729",
  "capacity": 2660,
  "voltage": 10000,
  "resistance": 10000,
  "kValue": 0.05,
  "grade": "A",
  "sortingTime": "2026-06-16 18:38:15"
}

成功响应 201

{
  "success": true,
  "data": {
    "id": 52,
    "barcode": "9146I2101883",
    "batchNo": "BAT-649729",
    "voltage": 10000,
    "internalResistance": 10000,
    "capacity": "2660",
    "kValue": 0.05,
    "sortingTime": "2026-06-16T10:38:15.000Z",
    "grade": "A",
    "importSource": "sorter"
  },
  "message": "分选数据接收成功"
}

4.2 批量上传

POST /api/cells/sorter-upload/bulk

请求体示例

{
  "cells": [
    {
      "barcode": "9146I2101883",
      "batchNo": "BAT-649729",
      "capacity": "2600-2650",
      "voltage": 3.685,
      "resistance": 19.8,
      "grade": "A"
    },
    {
      "barcode": "9146I2101884",
      "batchNo": "BAT-649729",
      "capacity": 2660,
      "voltage": 3.690,
      "internalResistance": 19.5,
      "grade": "A"
    }
  ]
}
💡 提示：批量接口的数组字段名是 cells。若数组内部存在重复 barcode，系统自动去重（仅保留最后一条）。整批使用事务，任一记录失败则全部回滚。

5. OCV1 测试机接口

OCV1 测试位于化成之后、分容之前，用于记录电芯的第一次开路电压（OCV）测试数据。OCV1 数据可先于分选机上传，系统会自动创建"半成品"电芯记录。

5.1 单条上传

POST /api/cells/ocv1-upload

请求体参数

参数名类型必填说明
barcodestring是电芯条码（最大 32 字符）
batchNostring是所属批次号
voltagenumber否OCV1 测试电压
resistance / internalResistancenumber否OCV1 测试内阻
testTimestring否OCV1 测试时间
equipmentCodestring否OCV1 测试设备编号（不验证字典）

请求体示例

{
  "barcode": "9146I2101883",
  "batchNo": "BAT-649729",
  "voltage": 3.685,
  "resistance": 19.5,
  "testTime": "2026-06-16 18:38:15",
  "equipmentCode": "OCV-001"
}

成功响应 201

{
  "success": true,
  "data": {
    "id": 53,
    "barcode": "9146I2101883",
    "batchNo": "BAT-649729",
    "importSource": "ocv1",
    "ocv1Voltage": 3.685,
    "ocv1Resistance": 19.5,
    "ocv1Time": "2026-06-16T10:38:15.000Z",
    "ocv1EquipmentCode": "OCV-001"
  },
  "message": "OCV1测试数据接收成功"
}

5.2 批量上传

6. OCV2 测试机接口

OCV2 测试位于分容之后、分选之前，用于记录电芯的第二次开路电压测试数据（通常用于计算 K 值）。

6.1 单条上传

POST /api/cells/ocv2-upload

请求体参数

参数名类型必填说明
barcodestring是电芯条码
batchNostring是所属批次号
voltagenumber否OCV2 测试电压
resistance / internalResistancenumber否OCV2 测试内阻
kValuenumber否K 值（自放电率）
testTimestring否OCV2 测试时间
equipmentCodestring否OCV2 测试设备编号

请求体示例

{
  "barcode": "9146I2101883",
  "batchNo": "BAT-649729",
  "voltage": 3.682,
  "resistance": 19.6,
  "kValue": 0.05,
  "testTime": "2026-06-17 10:00:00",
  "equipmentCode": "OCV-002"
}

成功响应 201

{
  "success": true,
  "data": {
    "id": 53,
    "barcode": "9146I2101883",
    "batchNo": "BAT-649729",
    "kValue": 0.05,
    "importSource": "ocv1",
    "ocv1Voltage": 3.685,
    "ocv1Resistance": 19.5,
    "ocv2Voltage": 3.682,
    "ocv2Resistance": 19.6,
    "ocv2Time": "2026-06-17T02:00:00.000Z",
    "ocv2EquipmentCode": "OCV-002"
  },
  "message": "OCV2测试数据接收成功"
}
💡 K 值优先级：OCV2 的 kValue 会同步写入 cell_barcode.kValue 字段。若后续分选机也上传了 kValue，将以分选机为准（覆盖 OCV2 的值）。

6.2 批量上传

POST /api/cells/ocv2-upload/bulk

请求体示例

{
  "ocv2Records": [
    {
      "barcode": "9146I2101883",
      "batchNo": "BAT-649729",
      "voltage": 3.682,
      "resistance": 19.6,
      "kValue": 0.05,
      "equipmentCode": "OCV-002"
    },
    {
      "barcode": "9146I2101884",
      "batchNo": "BAT-649729",
      "voltage": 3.688,
      "resistance": 19.7,
      "kValue": 0.06,
      "equipmentCode": "OCV-002"
    }
  ]
}

8. 硬件部署指南

8.1 网络互通

  1. 确保测试设备工控机与 MES 服务器处于同一个局域网内。
  2. 在工控机上运行 ping {MES服务器IP}，确保网络可达。

8.2 配置目标 URL

在设备的"数据上传配置"中，配置目标 API 地址：

设备URL
分选机http://{MES_IP}:3001/api/cells/sorter-upload
OCV1 测试机http://{MES_IP}:3001/api/cells/ocv1-upload
OCV2 测试机http://{MES_IP}:3001/api/cells/ocv2-upload

8.3 安全防护

由于这些接口免 Token 认证，为了防止数据被恶意篡改，必须在服务器的防火墙或网关上设置白名单，仅允许测试设备工控机的 IP 地址访问 3001 端口。

8.4 业务前置条件

测试设备上传数据前，操作工必须先在 MES 系统中创建好对应的批次号（如 BAT-649729），否则接口会返回 404 错误。

8.5 接口日志

所有 6 个接口的调用日志都会被自动记录到 sorter_api_log 表中，保留 3 天。可在 MES 系统的"系统管理 → 接口日志"页面查看，按 api_type 字段（sorter / ocv1 / ocv2）筛选。
