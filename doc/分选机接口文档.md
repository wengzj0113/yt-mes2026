# 分选机数据接口文档 v2.0

## 1. 概述

YT-MES 系统为分选机等外部硬件设备提供标准 REST API 接口，用于将电芯测试数据上传至系统 `cell_barcode` 数据表。
接口采用**无状态设计**，免登录认证（`@Public()`），方便硬件设备直接调用。

| 项目 | 说明 |
| :--- | :--- |
| **接口风格** | RESTful API |
| **数据格式** | JSON |
| **认证方式** | 免认证（无需 Token） |
| **Base URL** | `http://{服务器地址}:3001/api/cells` 或 `http://{服务器地址}/api/cells` (通过Nginx) |
| **目标数据表** | `cell_barcode` |
| **数据来源标记** | 通过此接口导入的数据，`import_source` 自动标记为 `'sorter'` |

> ⚠️ **安全提醒：** 接口免 Token 认证，生产环境**必须**通过防火墙、网关白名单等方式限制访问来源 IP，仅允许分选机所在网段调用。

---

## 2. 接口端点

| 方法 | 端点 | 用途 |
| :--- | :--- | :--- |
| `POST` | `/api/cells/sorter-upload` | **单条实时上传** — 分选机每测完一个电芯实时上传一条数据 |
| `POST` | `/api/cells/sorter-upload/bulk` | **批量上传** — 将本地表格数据或缓存数据一次性推送 |

---

## 3. 单条上传接口

### 3.1 接口地址
```http
POST /api/cells/sorter-upload
Content-Type: application/json
```

### 3.2 请求体格式
```json
{
  "barcode": "E2405A0000000000000000000000001",
  "batchNo": "WT26A1XZ8",
  "capacity": 20500.00,
  "voltage": 3.6500,
  "internalResistance": 1.25,
  "kValue": 0.0800,
  "grade": "A",
  "sortingTime": "2026-05-10T14:30:00.000Z"
}
```

### 3.3 字段说明

| 字段 | 类型 | 必填 | 数据库类型 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `barcode` | string | **是** | nvarchar(32) | 电芯条码（唯一标识，≤ 32 字符） |
| `batchNo` | string | **是** | nvarchar(16) | 所属批次号（需先在系统中创建该批次） |
| `capacity` | number | 否 | decimal(8,2) | 电芯容量（mAh） |
| `voltage` | number | 否 | decimal(6,4) | 开路电压（V） |
| `internalResistance` | number | 否 | decimal(6,2) | 交流内阻（mΩ）<br>**注意：** 字段名是 `internalResistance`，不是 `resistance` |
| `kValue` | number | 否 | decimal(6,4) | K 值（自放电率，mV/h） |
| `grade` | string | 否 | nvarchar(16) | 分选档位（A / B / C） |
| `sortingTime` | string | 否 | datetime2 | 分选时间（推荐 ISO 8601 格式） |

> 💡 **提示：** `capacity`、`voltage`、`internalResistance`、`kValue`、`grade`、`sortingTime` 均为**可选字段**，可根据分选机的实际测试能力选择性上传。

### 3.4 成功响应
*   **HTTP 状态码**：`201 Created`
```json
{
  "data": {
    "id": 12345,
    "barcode": "E2405A0000000000000000000000001",
    "batchNo": "WT26A1XZ8",
    "capacity": 20500.00,
    "voltage": 3.65,
    "internalResistance": 1.25,
    "kValue": 0.08,
    "grade": "A",
    "sortingTime": "2026-05-10T14:30:00.000Z",
    "importSource": "sorter",
    "importedAt": "2026-05-25T08:30:00.000Z",
    "createdAt": "2026-05-25T08:30:00.000Z"
  },
  "message": "分选数据接收成功"
}
```

### 3.5 错误响应

#### 批次不存在
*   **HTTP 状态码**：`404 Not Found`
```json
{
  "error": "Not Found",
  "message": "批次 WT26XXXX 不存在",
  "statusCode": 404
}
```

#### 条码重复
*   **HTTP 状态码**：`409 Conflict`
```json
{
  "error": "Conflict",
  "message": "电芯码 E2405A0000000000000000000000001 已存在",
  "statusCode": 409
}
```

## 4. 批量上传接口

### 4.1 接口地址
```http
POST /api/cells/sorter-upload/bulk
Content-Type: application/json
```

### 4.2 请求体格式
```json
{
  "cells": [
    {
      "barcode": "E2405A0000000000000000000000001",
      "batchNo": "WT26A1XZ8",
      "capacity": 20500.00,
      "voltage": 3.65,
      "internalResistance": 1.25,
      "kValue": 0.08,
      "grade": "A",
      "sortingTime": "2026-05-10T14:30:00.000Z"
    },
    {
      "barcode": "E2405A0000000000000000000000002",
      "batchNo": "WT26A1XZ8",
      "capacity": 20300.00,
      "voltage": 3.64,
      "internalResistance": 1.30,
      "kValue": 0.06,
      "grade": "B",
      "sortingTime": "2026-05-10T14:30:05.000Z"
    }
  ]
}
```

> ⚠️ **注意：** 批量接口的数组字段名是 `cells`（不是 `records`），每条记录结构与单条接口完全一致。

### 4.3 去重校验机制
批量接口自动执行**两层全量前置校验**（所有校验在写入数据库前完成，不会部分写入）：
1.  **请求体内去重** — 检查 `cells` 数组中是否存在重复的 `barcode`。
2.  **数据库去重** — 检查每条条码是否已存在于 `cell_barcode` 表中。

*只要发现任意一条重复，**整个请求全部拒绝**，并返回具体的冲突条码信息。*

#### 请求体内存在重复条码
*   **HTTP 状态码**：`400 Bad Request`
```json
{

```

*   **HTTP 状态码**：`409 Conflict`
```json
{
  "error": "Conflict",
  "message": "电芯码 E2405A0000000000000000000000001, E2405A0000000000000000000000003 已存在",
  "statusCode": 409
}
```

            "batchNo": "WT26A1XZ8",

## 6. 硬件连接与部署指南

分选机通常由一台工控机（PC）控制，连接步骤如下：

1.  **网络互通**：
    *   确保分选机工控机与 MES 服务器（`192.168.3.147`）处于**同一个局域网**内。
    *   在分选机工控机上打开命令行，运行 `ping 192.168.3.147`，确保网络是通的。
2.  **配置目标 URL**：
    *   在分选机控制软件的“数据上传配置”中，将目标 API 地址设置为：
        *   如果直接连后端：`http://192.168.3.147:3001/api/cells/sorter-upload`
        *   如果通过 Nginx 转发：`http://192.168.3.147/api/cells/sorter-upload`
3.  **安全防护（重要）**：
    *   由于该接口免 Token 认证，为了防止数据被恶意篡改，**必须在服务器的防火墙或网关上设置白名单**，仅允许分选机工控机的 IP 地址访问 `3001` 端口。
4.  **业务前置条件**：
    *   分选机在上传数据前，操作工必须先在 MES 系统中**创建好对应的批次号**（如 `WT26A1XZ8`），否则分选机上传数据时会报 `404 Not Found` 错误。
