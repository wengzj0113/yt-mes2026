1. 概述

YT-MES 为分选机（Sorter）等外部硬件设备提供了两个独立的 REST API 接口，用于将电芯测试数据上传到系统。

项目说明
接口用途接收分选机上传的电芯测试数据
目标数据表cell_barcode（电芯条码表）
认证方式免认证 — @Public() 装饰器，无需 JWT Token
数据来源标记import_source 自动标记为 'sorter'
基础路径http://<服务器地址>:3001/api/cells
安全提醒：部署上线后必须在防火墙/网关层限制访问来源 IP，仅允许分选机所在网段调用。

2. 接口端点

POST/api/cells/sorter-upload单条实时上传
POST/api/cells/sorter-upload/bulk批量上传
端点使用场景
POST /api/cells/sorter-upload分选机每测完一个电芯，实时上传一条数据。在线流水式生产。
POST /api/cells/sorter-upload/bulk将本地表格数据一次性推送。离线转存或整批导入。

3. 单条实时上传

3.1 请求格式

POST /api/cells/sorter-upload
Content-Type: application/json

{
  "barcode": "E2405A0000000000000000000000001",
  "batchNo": "WT26A1XZ8",
  "capacity": 20500.00,
  "voltage": 3.6500,
  "internalResistance": 1.25,
  "kValue": 0.0800,
  "grade": "A",
  "sortingTime": "2026-05-10T14:30:00.000Z"
}

3.2 字段说明

字段类型必填说明
barcodestring是电芯条码（唯一标识，≤ 32 字符）
batchNostring是所属批次号（需先在系统中创建）
capacitynumber否电芯容量（mAh）
voltagenumber否开路电压（V）
internalResistancenumber否交流内阻（mΩ）
kValuenumber否K 值，自放电率（mV/h）
gradestring否分选档位（A / B / C）
sortingTimestring否分选时间（ISO 8601 格式）
注意字段名：内阻字段名为 internalResistance，对应数据库列 internal_resistance。

3.3 成功响应

HTTP 状态码：201 Created

{
  "data": {
    "id": 12345,
    "barcode": "E2405A0000000000000000000000001",
    "batchNo": "WT26A1XZ8",
    "capacity": 20500.00,
    "voltage": 3.65,
    "internalResistance": 1.25,
    "kValue": 0.08,
    "grade": "A",
    "sortingTime": "2026-05-10T14:30:00.000Z",
    "importSource": "sorter",
    "importedAt": "2026-05-25T08:30:00.000Z",
    "createdAt": "2026-05-25T08:30:00.000Z"
  },
  "message": "分选数据接收成功"
}

3.4 错误响应

批次不存在

HTTP 404 Not Found

{
  "error": "Not Found",
  "message": "批次 WT26XXXX 不存在",
  "statusCode": 404
}

条码重复

HTTP 409 Conflict

{
  "error": "Conflict",
  "message": "电芯码 E2405A0000000000000000000000001 已存在",
  "statusCode": 409
}

4. 批量上传

4.1 请求格式

POST /api/cells/sorter-upload/bulk
Content-Type: application/json

{
  "cells": [
    {
      "barcode": "E2405A0000000000000000000000001",
      "batchNo": "WT26A1XZ8",
      "capacity": 20500.00,
      "voltage": 3.65,
      "internalResistance": 1.25,
      "kValue": 0.08,
      "grade": "A",
      "sortingTime": "2026-05-10T14:30:00.000Z"
    },
    {
      "barcode": "E2405A0000000000000000000000002",
      "batchNo": "WT26A1XZ8",
      "capacity": 20300.00,
      "voltage": 3.64,
      "internalResistance": 1.30,
      "kValue": 0.06,
      "grade": "B",
      "sortingTime": "2026-05-10T14:30:05.000Z"
    }
  ]
}
注意：数组字段名为 cells（不是 records），每条记录结构与单条接口一致。

4.2 去重校验

批量接口自动执行两层全量前置校验（写入前完成，不部分写入）：

  1. 请求体内去重 — 检查 cells 数组中是否存在重复条码，发现则返回 400
  2. 数据库去重 — 检查每条条码是否已存在于数据库，发现则返回 409 并列出冲突条码

4.3 成功响应

HTTP 状态码：201 Created

{
  "data": [
    { "id": 12345, "barcode": "E2405A...", "batchNo": "WT26A1XZ8", ... },
    { "id": 12346, "barcode": "E2405A...", "batchNo": "WT26A1XZ8", ... }
  ],
  "message": "批量分选数据接收成功"
}

4.4 错误响应

请求体内重复

HTTP 400 Bad Request

{
  "error": "Bad Request",
  "message": "导入数据中存在重复的电芯条码",
  "statusCode": 400
}

批次不存在

HTTP 404 Not Found

{
  "error": "Not Found",
  "message": "批次 WT26XXXX, WT26YYYY 不存在",
  "statusCode": 404
}

数据库重复

HTTP 409 Conflict

{
  "error": "Conflict",
  "message": "电芯码 E2405A...0001, E2405A...0003 已存在",
  "statusCode": 409
}

7. 注意事项

1. 网络安全

接口免 Token 认证，部署后务必限制来源 IP。

2. 条码规范

barcode ≤ 32 字符，系统唯一，重复上传将被拒绝。

3. 批次预创建

batchNo 对应的批次必须提前创建，否则返回 404。

4. 批量上限

单次建议 ≤ 10000 条，超过请分批调用。

5. 全量前置校验

任意一条数据重复则全部拒绝，不会部分写入。

6. 日期格式

推荐使用 ISO 8601 格式（如 2026-05-10T14:30:00.000Z）。

7. 字段命名

使用驼峰命名：internalResistance、sortingTime、batchNo。
