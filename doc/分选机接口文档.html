分选机数据接口文档 v2.0

1. 概述

YT-MES 系统为分选机等外部硬件设备提供标准 REST API 接口，用于将电芯测试数据上传至系统 cell_barcode 数据表。 接口采用无状态设计，免登录认证（@Public()），方便硬件设备直接调用。

项目说明
接口风格RESTful API
数据格式JSON
认证方式免认证（无需 Token）
Base URLhttp://{服务器地址}:3001/api/cells
目标数据表cell_barcode
数据来源标记通过此接口导入的数据，import_source 自动标记为 'sorter'
安全提醒：接口免 Token 认证，生产环境必须通过防火墙、网关白名单等方式限制访问来源 IP， 仅允许分选机所在网段调用。

2. 接口端点

方法端点用途
POST /api/cells/sorter-upload 单条实时上传 — 分选机每测完一个电芯实时上传一条数据
POST /api/cells/sorter-upload/bulk 批量上传 — 将本地表格数据一次性推送

3. 单条上传接口

3.1 接口地址

POST /api/cells/sorter-upload
Content-Type: application/json

3.2 请求体格式

{
  "barcode": "E2405A0000000000000000000000001",
  "batchNo": "WT26A1XZ8",
  "capacity": 20500.00,
  "voltage": 3.6500,
  "internalResistance": 1.25,
  "kValue": 0.0800,
  "grade": "A",
  "sortingTime": "2026-05-10T14:30:00.000Z"
}

3.3 字段说明

字段 类型 必填 数据库精度 说明
barcode string 是 nvarchar(32) 电芯条码（唯一标识，≤ 32 字符）
batchNo string 是 nvarchar(16) 所属批次号（需先在系统中创建该批次）
capacity number 否 decimal(8,2) 电芯容量（mAh）
voltage number 否 decimal(6,4) 开路电压（V）
internalResistance number 否 decimal(6,2) 交流内阻（mΩ）
注意：字段名是 internalResistance，不是 resistance
kValue number 否 decimal(6,4) K 值（自放电率，mV/h）
grade string 否 nvarchar(16) 分选档位（A / B / C）
sortingTime string 否 datetime2 分选时间（推荐 ISO 8601 格式）
提示：capacity、voltage、internalResistance、kValue、grade、sortingTime 均为可选字段， 可根据分选机的实际测试能力选择性上传。无需 Token，无需额外鉴权。

批次不存在

4. 批量上传接口

4.1 接口地址

POST /api/cells/sorter-upload/bulk
Content-Type: application/json

4.2 请求体格式

{
  "cells": [
    {
      "barcode": "E2405A0000000000000000000000001",
      "batchNo": "WT26A1XZ8",
      "capacity": 20500.00,
      "voltage": 3.65,
      "internalResistance": 1.25,
      "kValue": 0.08,
      "grade": "A",
      "sortingTime": "2026-05-10T14:30:00.000Z"
    },
    {
      "barcode": "E2405A0000000000000000000000002",
      "batchNo": "WT26A1XZ8",
      "capacity": 20300.00,
      "voltage": 3.64,
      "internalResistance": 1.30,
      "kValue": 0.06,
      "grade": "B",
      "sortingTime": "2026-05-10T14:30:05.000Z"
    }
  ]
}
注意：批量接口的数组字段名是 cells（不是 records）， 每条记录结构与单条接口完全一致。

4.3 去重校验机制

批量接口自动执行两层全量前置校验（所有校验在写入数据库前完成，不会部分写入）：

  • 请求体内去重 — 检查 cells 数组中是否存在重复的 barcode
  • 数据库去重 — 检查每条条码是否已存在于 cell_barcode 表中

只要发现任意一条重复，整个请求全部拒绝，并返回具体的冲突条码信息。

7. 注意事项

  • 网络安全：接口免 Token 认证，部署后必须在防火墙/网关层限制来源 IP
  • 条码规范：barcode ≤ 32 字符，系统唯一，重复上传将被拒绝
  • 批次预创建：batchNo 对应的批次必须提前在 MES 中创建
  • 批量上限：单次建议 ≤ 10000 条，超过请分批调用
  • 全量前置校验：批量接口发现任意重复则全部拒绝，不会部分写入
  • 字段命名：注意使用驼峰命名 internalResistance（不是 resistance）、sortingTime（不是 sorting_time）、batchNo（不是 batch_no）
  • 数组字段：批量接口的数组字段名为 cells（不是 records）
  • 日期格式：推荐使用 ISO 8601 格式（如 2026-05-10T14:30:00.000Z）
