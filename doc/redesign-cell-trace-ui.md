# 电芯追溯页面 UI 重新设计方案

## 概述
对 YT-MES 系统的电芯追溯页面（CellTracePage.vue）进行 UI 重新设计，采用工业控制台风格，提升信息密度和可读性。

## 设计理念
"工业控制台"风格 — 借鉴 SCADA 和工业 MES 设计语言：
- 高信息密度，一屏可见
- 深色导航 + 浅色内容的高对比
- 状态颜色语义化（绿/橙/灰/红）
- 流程管道作为视觉核心
- 参数展示仪表化、结构化

## 布局结构
```
┌────────────────────────────────────────────┐
│ [搜索栏 - 始终可见]                         │
├─────────┬──────────────────────────────────┤
│ 工序导航 │  KPI 卡片 (电压/内阻/容量/等级)   │
│ (13道)  │  条码展示                          │
│         │  工序进度条 × 批次信息             │
│         │  工序详情 (分组展示)               │
│         │  电芯列表 (批次模式)               │
└─────────┴──────────────────────────────────┘
```

## 核心变更
1. **Hero 区域 → 紧凑搜索栏**：72px 固定搜索栏取代 300px+ 的 Hero 区域
2. **水平滚动 pipeline → 左侧工序导航**：160px 宽侧边栏，13 道工序垂直排列
3. **平铺信息 → KPI 仪表卡片**：电压、内阻、容量、等级以仪表风格展示
4. **无分组详情 → 分组展示**：按设备参数、工艺参数、操作信息分组
5. **新增进度条**：底部显示完成度进度条和百分比
6. **响应式**：支持 768/1024/1440 三个断点

## 技术实现
- 框架：Vue 3 + Composition API + TypeScript
- UI：Element Plus
- 测试：Vitest + @vue/test-utils（41 个测试全部通过）
- 单文件组件：CellTracePage.vue（template + script + scoped style）

## 文件变更
- `web/src/views/cells/CellTracePage.vue` — 完全重写
- `web/src/views/cells/CellTracePage.spec.ts` — 完整测试套件（从 3 个扩至 18 个测试用例）
